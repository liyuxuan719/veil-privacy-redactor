# Contributing

## Development

```bash
pnpm install
pnpm start
pnpm test
pnpm check
```

The app is static; no bundler is required. Keep the production files deployable directly from the repository root.

## Privacy Rules

- Do not add image upload, remote inference, analytics, session replay, or cloud error reporting.
- Do not add third-party runtime scripts from a CDN. Vendor and document them.
- Keep `connect-src 'self'` in the CSP unless a reviewed design change explicitly requires otherwise.
- Do not persist source images, OCR text, face data, or detection results.
- Do not claim that automatic redaction guarantees anonymity.

## Test Images

Use only:

- synthetic screenshots generated by the project;
- public-domain or permissively licensed test images;
- images that have been fully de-identified.

Do not submit real identity documents, private faces, live phone numbers, vehicle registrations, or personal screenshots.

## Pull Requests

Please include:

- a short description of user-visible behavior;
- tests for new matching or geometry logic;
- any model/version/license changes;
- desktop and mobile screenshots for significant visual changes;
- confirmation that the browser Network panel shows no unexpected external requests.
